⚙️ Configuration Steps

1

Install the Module

Go to Apps → Search "Product Badges" → Install

After installation, 6 badge templates are automatically created and ready to use.

2

View All Badges

  • Go to Website → eCommerce → Ribbons
  • You will see all 6 pre-built badges: NEW, SALE, HOT, BESTSELLER, LOW STOCK, FEATURED
  • Click any badge to edit colors, position, and style
3

Assign Badge to a Single Product

  • Go to Website → eCommerce → Products
  • Open any product
  • Find the "Ribbon" field in the Sales tab
  • Select a badge (e.g. HOT or FEATURED)
  • Click Save
  • Visit your website — the badge appears on the product image
4

Bulk Assign Badge to Multiple Products

  • Go to Website → eCommerce → Products (list view)
  • Tick the checkboxes of 2 or more products
  • Click Action → Assign Badge
  • Select badge and action (Assign or Remove)
  • Click Apply
5

Configure Auto-Assign Rules

Open BESTSELLER badge and set:

  • Min. Sales Qty — products sold more than this get the badge (default: 10)

Open LOW STOCK badge and set:

  • Stock below — products with qty below this get the badge (default: 5)
Note: Only one badge per auto-assign type is allowed (one BESTSELLER, one LOW STOCK, etc.)
6

Apply Auto Rules Manually

  • Open the BESTSELLER or LOW STOCK badge
  • Click the "Apply Rule Now" button at the top
  • All matching products get the badge instantly
7

Enable Daily Auto-Update (Cron Job)

  • Go to Settings → Technical → Scheduled Actions
  • Find "Product Badges: Auto Apply Rules"
  • Toggle Active → On
  • Runs daily — badges stay automatically updated
8

Customize Badge Colors & Style

  • Open any badge in Website → eCommerce → Ribbons
  • Change Background Color and Text Color with color picker
  • Set Position: Left or Right
  • Set Style: Ribbon (banner) or Badge (tag)
  • Click Save — changes apply immediately on website
